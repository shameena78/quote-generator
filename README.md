# 💬 Quote Generator

A simple and interactive Quote Generator built using HTML, CSS, and JavaScript. Generate inspiring and motivational quotes with a clean and user-friendly interface.

## ✨ Features

- 🎯 Generates quotes dynamically
- 💡 Includes motivational and inspirational quotes
- 🖥️ Simple and clean user interface
- ⚡ Built with vanilla JavaScript
- 📱 Easy to use

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click the button to generate a quote.
